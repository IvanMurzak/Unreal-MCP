Unreal-MCP drives the Unreal Editor that is open on this project. Prefer its tools to shell commands and file edits for anything the editor holds: levels, actors, assets, Blueprints, Widget Blueprints, collision, project settings. Load the tools you need in one tool search (rql-query and rql-mutate read and change anything in RQL; python-execute runs Unreal Python; source-compile builds the C++ while the editor runs).
To run the game and see its errors, play-test inside this editor: rql-mutate editor | call StartPlay() then AdvancePlay(3), rql-query console | where Verbosity == "Error", then StopPlay(). Do not start UnrealEditor -game or another editor from the shell.
