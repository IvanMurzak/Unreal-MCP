Unreal-MCP drives the Unreal Editor that is open on this project: prefer its tools to shell commands for anything in the editor. python-execute (Unreal Python) handles most reads and edits; rql-query / rql-mutate cover Blueprint graphs, Widget Blueprints, collision channels and bulk edits; source-compile builds the project's C++ while the editor runs.
To run the game and see its errors, play-test inside this editor: rql-mutate editor | call StartPlay() then AdvancePlay(3), rql-query console | where Verbosity == "Error", then StopPlay(). Never start UnrealEditor -game or a second editor from the shell.
